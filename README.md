# 🎬 Video to AI Prompt Generator

এটি একটি সহজ এবং শক্তিশালী **Streamlit** ওয়েব অ্যাপ্লিকেশন যা **Google Gemini 1.5 Flash AI** ব্যবহার করে যেকোনো ভিডিও অ্যানালাইসিস করে এবং সেটি থেকে বিস্তারিত প্রম্পট (Prompt) জেনারেট করে। এই প্রম্পটগুলো আপনি Midjourney, Runway, বা Sora-এর মতো AI টুলগুলোতে ব্যবহার করতে পারবেন।

## ✨ বৈশিষ্ট্য (Features)
- 📁 **সহজ আপলোড:** MP4, MOV, এবং AVI ফরম্যাটের ভিডিও সাপোর্ট করে।
- 🧠 **AI অ্যানালাইসিস:** ভিডিওর দৃশ্য, ক্যামেরা মুভমেন্ট এবং লাইটিং বুঝতে সক্ষম।
- 📝 **স্মার্ট প্রম্পট:** সরাসরি কপি করার উপযোগী টেক্সট প্রম্পট আউটপুট দেয়।
- 🚀 **দ্রুত প্রসেসিং:** Gemini 1.5 Flash মডেল ব্যবহারের কারণে খুব দ্রুত ফলাফল পাওয়া যায়।

## 🛠️ টেকনোলজি (Tech Stack)
- **Language:** Python
- **Framework:** Streamlit
- **AI Model:** Google Gemini 1.5 Flash API
